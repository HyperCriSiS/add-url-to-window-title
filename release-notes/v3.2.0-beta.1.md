# Add URL To Window Title v3.2.0-beta.1

First prerelease of the modernized fork. This beta is intended for broader testing before a stable release.

## Highlights

- Reliable title tracking on dynamic pages and SPAs, including late-created, replaced, and moved `<title>` elements.
- Handles sites that repeatedly overwrite the title without duplicating the URL suffix.
- SPA navigation tracking without a permanent per-tab polling timer.
- Three URL display modes: hostname, full URL, and full URL without query/fragment.
- Optional focused-input `name` and `id` attributes for more specific password-manager rules.
- Toolbar diagnostics showing whether the current page is managed, overwritten, restricted, or unsupported.
- Manifest V3, Firefox Android metadata, and a dedicated Firefox extension ID for the fork.
- No runtime third-party dependencies and no background service worker.
- Modern lightweight options UI using native CSS.

## Validation

- Mozilla `web-ext` lint and reproducible package build.
- Dependency-free Node.js unit tests.
- Real Chromium extension E2E tests, including the diagnostics active-tab messaging path and a 40-simultaneous-tab smoke test.
- Firefox temporary-install E2E tests using the exact validated package.
- Live regressions corresponding to upstream GitHub/X issue #42 and Chase issue #41 have been reproduced and verified against the modernized implementation.

## Known beta gaps

The following validation is still pending before a stable release:

- Direct Waterfox desktop testing outside the WebDriver temporary-install path.
- Physical Firefox/Waterfox Android testing where extension installation is supported.
- Optional branded Google Chrome/store-specific validation before Chrome Web Store publication.
- An extreme long-lived/high-tab-count test approximating upstream issue #38 (~2700 tabs), beyond the existing 40-tab automated smoke test.

The automated Waterfox 6.6.17 diagnostic accepts the temporary add-on but does not inject even a minimal content script through its current WebDriver temporary-install path. It is therefore intentionally non-gating and does not claim Waterfox product compatibility yet.

## Android System WebView limitation

Third-party Android app-owned System WebViews do not load Firefox/Chrome WebExtensions. This beta cannot make arbitrary app WebViews support the extension. Browser-owned inherited-origin documents such as eligible `about:blank`, `data:` and `blob:` pages are handled where browser policy permits content-script injection.

## Installation

The attached ZIP is the unsigned extension package built from the validated release commit.

- **Firefox / Waterfox:** for development/testing, use `about:debugging` → **This Firefox** → **Load Temporary Add-on**. Normal Firefox distribution requires Mozilla signing/AMO.
- **Chromium-based browsers:** extract the package and load it as an unpacked extension for development/testing. Store publishing is separate.

`SHA256SUMS.txt` is attached for package verification.
